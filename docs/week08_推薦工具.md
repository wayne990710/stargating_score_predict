# 第 8 週產出：觀星日期推薦工具

計畫書第 8 週檢核目標：程式能正確輸出兩地指定期間的推薦日期排序。
程式：scripts/recommend.py。測試：tests/test_recommend.py（13 項，全部通過）。

## 一、怎麼用

```
python scripts/recommend.py --site hehuan --start 2027-03-01 --end 2027-05-31 --only-days-off
python scripts/recommend.py --site taipei --start 2026-10-01 --end 2026-10-31
```

| 參數 | 意義 | 預設 |
|---|---|---|
| `--site` | `hehuan` 合歡山觀星園、`taipei` 學校 | hehuan |
| `--start`、`--end` | 查詢區間（含兩端） | 必填 |
| `--window` | `night` 整夜（天文暮光結束到曙光開始）、`evening` 傍晚（天文暮光結束到 24:00） | 合歡山 night、學校 evening |
| `--only-days-off` | 只列隔天放假的晚上 | 不篩選 |
| `--min-dark` | 活動時段至少幾小時無月黑暗，不足的排最後 | 2 |
| `--top` | 報表顯示前幾名 | 15 |

輸出在 results/recommend/：CSV（Excel 可直接開）與 Markdown 表格。

## 二、分數怎麼算

**分數 = 晴天機率 × 活動時段中無月黑暗的比例**

| 成分 | 來源 |
|---|---|
| 晴天機率 | 該日所在半月（1–15 日、16 日–月底）「傍晚 20、21 時雲量都 ≤ 2 成」的歷史比例，附 95% 區間。合歡山：露點差代理判斷 2011–2025（暫定）。學校：臺北測站人工雲量 2008–2017（直接觀測）。2026 年資料不使用。 |
| 無月黑暗 | 每晚用星曆即時計算天文暮光與月出月沒，扣掉月亮在地平線上的時間。 |
| 假日 | 不乘權重，改為欄位「隔天放假」，可用 `--only-days-off` 篩選。2017–2027 依人事總處辦公日曆；其他年份只算週末。 |

## 三、這週改了什麼

1. **學校（臺北）原本會當掉**：缺機率表。新增 scripts/build_taipei_prob.py，從人工雲量標籤算出臺北半月與月機率（3,378 晚）。
2. **月亮改成看「活動時段」**：原本用整夜的無月比例，上弦和下弦常常分數相近，但上弦月傍晚就在天上。例如 2027-01-15，月亮 23:56 才落下：整夜有一半是黑的，但 24:00 前幾乎全被月光照到。2026-11 到 2027-06 的 242 晚中，整夜版與傍晚版的前 20 名只重疊 11（臺北）到 13（合歡山）晚，所以兩種時段要分開。學校小觀預設傍晚，合歡山過夜預設整夜。
3. **拿掉假日權重 0.6**：這個數字沒有根據。改成標示加篩選，由使用者決定。
4. **天文數值即時計算**：原本靠只到 2027 年的天文表，現在任何年份都能查。
5. **日曆邊界**：2027-12-31 以後原本會把隔天誤判為上班日，現在改用週末判斷並在「日曆來源」欄註明。
6. 輸入防呆：結束日早於開始日、區間超過兩年，會給出中文錯誤訊息。

## 四、怎麼確認「正確輸出」

測試的預期值來自和程式無關的來源：

| 檢查 | 獨立來源 | 結果 |
|---|---|---|
| 月出月沒時間（3 晚，兩地） | 美國海軍天文台 USNO 線上計算 | 差 1 分鐘內 |
| 2026 年 10 月每晚「隔天放假」 | 人事總處原始日曆 CSV | 30 晚全對 |
| 傍晚無月時數 | 由 USNO 月沒時間 20:38 手算到 24:00 = 3.37 小時 | 差 0.1 小時內 |
| 半月分界、閏年 2/29 | 直接查機率表 | 正確 |
| 臺北 1 月上半機率 | 從人工雲量標籤直接數 | 一致 |
| 兩地都能排出每一晚、排名不重複、依分數排序 | 程式性質 | 通過 |

## 五、範例：2027 年 3–5 月合歡山，只看隔天放假

| 排名 | 日期 | 晴天機率 | 月出 | 月沒 | 無月黑暗 | 隔天是 |
|---|---|---|---|---|---|---|
| 1 | 4/5（一） | 0.26 | 04:54 | - | 9.0 h | 補假 |
| 2 | 4/4（日） | 0.26 | 04:23 | - | 8.9 h | 清明節 |
| 3 | 4/3（六） | 0.26 | 03:51 | - | 8.4 h | 兒童節 |
| 4 | 3/6（六） | 0.23 | 05:21 | - | 9.7 h | |
| 6 | 4/2（五） | 0.26 | 03:20 | - | 7.9 h | |

4/2–4/4 大觀落在這三個月最好的時段。注意 4/5 是週一晚上，隔天補假，所以也算「隔天放假」。

## 六、限制

1. **同一個月內，排名幾乎只由月亮決定**：晴天機率每半個月才變一次，機率差 0.1 以內常在 95% 區間內，分不出高下。
2. **合歡山的晴天機率是暫定**：絕對數字不保證準（第 7 週：排序可搬、絕對值不可搬）。
3. **晴天機率只代表 20、21 時**：整夜時段的分數用的仍是傍晚的晴天機率。
4. **月亮只看有沒有在天上**：沒有考慮月亮亮度和高度，細月也會被當成不黑。
5. **學校行事曆不在內**：寒暑假、段考需要使用者自己判斷。
6. 臺北的人工雲量只到 2017 年。
